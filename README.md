## ⭐ Featured projects

### [SafeRoute](https://github.com/tahaserifaydin/SafeRoute) — safety-aware walking navigation
Normal maps only find the **fastest** route. SafeRoute scores every street segment (0–100) using **street lighting, pedestrian infrastructure, open-business density and recorded crime data**, then suggests a **safer** walking route — especially for people walking at night.
Pilot regions: Eindhoven & Nuenen (NL), with open data from OpenStreetMap and the Dutch police.
`JavaScript` `Node.js` `Python` `OpenStreetMap / Overpass`

### [Diabetes Risk iOS](https://github.com/tahaserifaydin/diabetes-risk-ios) — on-device ML on iPhone
A Random Forest trained in a Jupyter notebook, exported to **Core ML**, running fully on the device in a SwiftUI app. Compared KNN vs Random Forest, cut missed diabetic cases from 26 to 14, and replaced fake-precise percentages with **calibrated risk levels**.
`Python` `scikit-learn` `Core ML` `SwiftUI`
